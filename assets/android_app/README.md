2. Go to: **https://p01--news-engine-service--dkhqtlpvx6bh.code.run/**
3. Tap **Menu (⋮)** in Chrome and tap **'Install App'** or tap the **'📲 Install App'** button in the header.
4. Android will automatically mint a genuine native WebAPK with full standalone hardware access, haptics, and zero store fees (zsh.00).

## Option B: Native Android Studio Build
1. Open this folder in Android Studio.
2. Connect your Android phone via USB or start an emulator.
3. Click **Run > Run 'app'** or build an APK via **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Transfer the generated APK to your phone and install!
